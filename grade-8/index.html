1. Наглядная теория: физика фазовых переходов

Вещество в природе может переходить из одного агрегатного состояния в другое. В этом уроке рассматриваются два взаимно обратных перехода между твёрдым кристаллическим и жидким состояниями: плавление и отвердевание (кристаллизация).

Плавление (Твёрдое → Жидкость)

Переход вещества из твёрдого состояния в жидкое. Для этого кристаллу необходимо сообщить количество теплоты. Энергия тратится на разрыв связей в кристаллической решётке — потенциальная энергия молекул возрастает.

Отвердевание / кристаллизация (Жидкость → Твёрдое)

Переход вещества из жидкого состояния в твёрдое. При этом вещество отдаёт теплоту окружающей среде. Частицы выстраиваются в упорядоченную решётку, а их потенциальная энергия уменьшается.

Главное свойство кристаллических тел (§ 12): плавление и отвердевание данного кристаллического вещества происходят при одной и той же строго определённой температуре — температуре плавления \(t_{\text{пл}}\) (например, \(0\,^\circ\text{C}\) для льда, \(232\,^\circ\text{C}\) для олова, \(327\,^\circ\text{C}\) для свинца). Аморфные тела (стекло, воск, смола) не имеют кристаллической решётки, поэтому у них нет постоянной температуры плавления — они размягчаются постепенно.

График температурной зависимости \(t(\tau)\) и модель кристаллической решётки

На графике показан полный цикл: нагревание твёрдого тела (участок AB), плавление (плато BC), нагревание жидкости (CD), а затем охлаждение жидкости (DE), кристаллизация (плато EF) и остывание твёрдого тела (FK). Выберите вещество и перемещайте ползунок времени \(\tau\), чтобы увидеть, как меняются внутренняя энергия и кристаллическая решётка.

Кристаллическая решётка разрушается. В сосуде одновременно присутствуют твёрдая и жидкая фазы. Подводимое тепло идёт на рост потенциальной энергии молекул, поэтому температура не растёт.

Расчётная формула: Q = λ · m

Физический смысл удельной теплоты плавления \(\lambda\) (§ 14)

Разным кристаллическим веществам одинаковой массы требуется разное количество теплоты для разрушения решётки. Чтобы характеризовать это свойство вещества, вводят удельную теплоту плавления \(\lambda\) («лямбда»).

Основная формула (§ 14)
Q = λ · m
\(\lambda = \dfrac{Q}{m}\;\left[\dfrac{\text{Дж}}{\text{кг}}\right]\) \(m = \dfrac{Q}{\lambda}\;[\text{кг}]\)

Физический смысл: удельная теплота плавления показывает, какое количество теплоты необходимо сообщить кристаллическому телу массой \(1\text{ кг}\), взятому при температуре плавления, чтобы полностью перевести его в жидкое состояние при той же температуре.

Например, \(\lambda_{\text{льда}} = 3{,}4 \cdot 10^5\text{ Дж/кг}\) означает: для превращения \(1\text{ кг}\) льда при \(0\,^\circ\text{C}\) в воду при \(0\,^\circ\text{C}\) требуется \(340\,000\text{ Дж}\) теплоты. При кристаллизации \(1\text{ кг}\) воды при \(0\,^\circ\text{C}\) ровно столько же теплоты выделится.
